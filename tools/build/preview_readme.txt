SIM-DURTY | WINDOWS PREVIEW

Extract the complete preview ZIP into a folder, then open SIM-DURTY.exe.
Keep SIM-DURTY.pck next to SIM-DURTY.exe. Godot and Git are not required.

This is an infrastructure preview. It displays build information and a
COPY DEBUG REPORT button. No gameplay systems have been added yet.

For feedback, describe what happened and paste the copied debug report
into the development chat. BUILD-METADATA.json identifies this exact build
when the application cannot start.

CI verifies the packaged game starts headlessly on Windows. This does not
replace visual, input, clipboard, audio, or performance playtesting.

This development build is unsigned. Verify its source and checksum before
running it. Do not disable antivirus or other system security protections.

Recovery: keep the previous working preview in a separate folder. Never
mix EXE/PCK files from different builds. This version has no gameplay saves.
